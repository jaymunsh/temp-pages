# PickRoom (픽룸) - 프로젝트 핸드오프 (Handoff) 가이드

> **배포 페이지**: [https://jaymunsh.github.io/temp-pages/pickroom/](https://jaymunsh.github.io/temp-pages/pickroom/)  
> **메인 파일**: `index.html` (단일 파일 정적 웹 애플리케이션)  
> **최종 업데이트**: 2026-10-29

---

## 1. 프로젝트 개요

**PickRoom(픽룸)**은 책상 및 워크스테이션 환경 구성을 위한 스마트 셋업 큐레이션 서비스입니다.
별도의 빌드 도구(Webpack, Vite 등)나 무거운 프레임워크 없이 브라우저에서 바로 동작하는 **순수 Vanilla HTML5 / CSS3 / ES6+ 단일 파일 (`index.html`)**로 개발되었습니다.

현재 3가지 메인 탭으로 구성되어 있습니다:
1. **01 모션 데스크**: 10종 인기 모션데스크 실물 사진/스펙, 모터 규격, 다나와/네이버 최저가 비교
2. **02 데스크탑**: 예산별(150만~300만) 최적 견적 매트릭스, 완본체 핫딜 실구매가 비교 및 구매 주의사항
3. **03 모니터**: 본체 스펙 체급 매칭표 및 추천 게이밍/작업용 모니터 10종 실물 사진, 다나와 최저가 큐레이션

## 2. 탭별 구현 현황 및 기능

### 01 모션 데스크 (`tab: 'desk'`)
- **데이터**: `products.desk` (10종 - 루나랩, 데스커, 플렉시스팟, 에렉투스, 이케아 등)
- **주요 기능**:
  - 실물 제품 이미지(`image`), 모터 규격(듀얼모터 / 싱글모터) 필터 및 브랜드/유형 필터
  - 스펙 매트릭스, 브랜드 공식 AS 기간, 상판 두께, 허용 하중 정보
  - 상단 접이식 가이드박스 (`#guide-box`): 높이 조절 가이드 및 구매 팁
  - 하단 비교함(`selected` Set 기반) 연동

### 02 데스크탑 (`tab: 'pc'`)
- **데이터 출처**: `데스크톱 가격대별 사양 비교.pdf`
- **데이터**: `products.pc` (150만원대, 200만원대, 250만원대, 300만원대)
- **상단 매트릭스 (`#pc-matrix-section`)**:
  - 다나와 단품 조립 견적가 vs 특가 완본체 체감가(핫딜 체감가) 실시간 비교표
  - **3대 원가절감 방어팁** (`<details>` 아코디언):
    1. SSD 디램리스 탑재 여부 (P41, P31, 980 PRO 권장)
    2. 단일 RAM 원가절감 방지 (16GB 단일 대신 16GB x 2 듀얼채널 필수)
    3. 그래픽카드 권장 정격 파워 규격 (4070S 700W+, 4070TiS/4080S 850W+ 골드)
- **하단 카드 UI (`compactPC`)**:
  - 모션데스크보다 가로로 슬림한 컴팩트 카드 형태
  - CPU, GPU, RAM, SSD, 파워, 쿨러 칩 표기
  - 다나와 단품가와 핫딜 목표가를 함께 표시하고 다나와 검색 링크 연동

### 03 모니터 (`tab: 'monitor'`)
- **데이터**: `products.monitor` (10종 모두 다나와 공식 CDN 고해상도 실물 이미지 `image` 연동 완료)
  - **FHD (가성비)**: 한성 TFG27F14P2 (~16만)
  - **QHD (27" 주류)**: 기가바이트 GS27QA (~21만), 필립스 27M2N3501PF (~24만), LG 27GS85Q (~39만), 알파스캔 Q27G4S (~43만)
  - **QHD (32" 대화면)**: MSI MAG 325QF700 (~24만), 삼성 오디세이 G5 S32FG500 (~27만)
  - **4K UHD (하이엔드)**: 한성 TFG27U1224PMW Mini-LED (~38만), LG 32GR93U (~66만), ASUS ROG Swift XG32UCG (~99만)
- **상단 매트릭스 (`#monitor-matrix-section`)**:
  - 본체 사양 체급(150만~300만)과 최적 매칭되는 권장 모니터 해상도/주사율 가이드
- **하단 카드 UI (`compactMonitor`)**:
  - **실물 제품 사진 (`.mon-img`) 노출**: 모바일/태블릿/데스크탑 전 반응형 뷰포트에서 최적 크기 유지
  - 패널 종류(Fast IPS, Rapid IPS, Mini-LED, Fast VA), 주사율(144~300Hz), 밝기/HDR 스펙 표기
  - 다나와 정식 상품 페이지 직링크 및 네이버 최저가 검색 링크 연동

## 3. 코드 아키텍처 및 상태 관리

모든 로직은 `index.html` 내 `<script>` 태그 안에 위치합니다.

### 핵심 상태 변수
```javascript
let tab = 'desk';          // 현재 활성 탭: 'desk' | 'pc' | 'monitor'
let filter = '전체';       // 상단 카테고리 필터 칩 값
let motorFilter = '전체';  // 데스크 탭 전용 모터 필터 ('전체' | '싱글' | '듀얼')
const selected = new Set(); // 비교함에 담긴 아이템 ID 목록
const tabList = ['desk', 'pc', 'monitor']; // 키보드 접근성 순환 탭 목록
```

### 주요 함수
- `switchTab(value)`:
  - 탭 상태 변경 및 `aria-selected`, `tabindex` 등 웹 접근성 속성 동기화
  - 데스크탑 매트릭스(`#pc-matrix-section`), 모니터 매트릭스(`#monitor-matrix-section`), 모터 툴바(`#motor-tools`), 가이드 박스(`#guide-box`)의 `hidden` 속성 토글
- `render()`:
  - 현재 탭에 맞는 필터 버튼 동적 생성 (`products[tab]`의 `type` 기준)
  - 탭별 렌더러 분기:
    - `desk` -> `compactDesk(p)`
    - `pc` -> `compactPC(p)`
    - `monitor` -> `compactMonitor(p)`
- `renderComparison()`:
  - 하단 비교함 드로어 렌더링 (담긴 아이템의 스펙/가격 비교표 출력)

## 4. 후속 작업 제안 (Next Steps for Next Agent)

1. **데스크탑 + 모니터 + 데스크 세트 견적 시뮬레이터**:
   - 사용자가 각 탭에서 1개씩 선택하면 총 견적(단품가 기준 및 핫딜가 기준)과 할인율을 계산해주는 종합 셋업 계산기 추가.
2. **다나와 가격 데이터 갱신 자동화**:
   - 주기적으로 다나와 최저가를 스크래핑하거나 JSON 파일(`data/products.json`)로 분리하여 데이터 업데이트 용이성 확보.
3. **모니터 상세 필터링 강화**:
   - 크기(27인치, 32인치), 패널(IPS, VA, Mini-LED), 주사율(144Hz, 180Hz, 240Hz+) 다중 필터 추가.
4. **반응형 모바일 UI 검수**:
   - 모바일 뷰포트(375px~430px)에서 스펙 매트릭스 테이블의 가로 스크롤 터치 UX 개선.
