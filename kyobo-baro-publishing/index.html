전체 흐름부터 살펴보세요

처음이라면 이 세 가지만 기억하세요. 회원 가입 → 책 파일 준비 → 판매신청입니다.

오늘 할 일

파트너 가입을 신청하고, 책 제목·저자명·책 크기를 정하세요.

준비할 결과물

책 안쪽 페이지 PDF와 표지입니다. 개인저자는 무료표지도 이용할 수 있어요.

확인 포인트

아래의 출간 작업표에 책 정보와 진행 일정을 적을 수 있어요.

자세한 절차와 작업표 보기＋
  1. 파트너시스템 (새 창)을 PC에서 열고 ‘파트너 가입’을 누른다. 사업자가 없는 저자는 ‘개인저자’를 고른다.
  2. 아래 ‘출간 작업표’를 채운다. 도서명·저자명·판형·페이지 수·용지를 우선 결정한다.
  3. 공식 제작 가이드 (새 창)에서 사양을 선택하고 내지 템플릿과 표지 PPT를 받는다.
  4. 원고를 템플릿에 편집하고 PDF로 저장한다. 본문 페이지 수가 바뀌면 책등과 표지도 다시 계산한다.
  5. POD 등록 STEP 1~5를 작성하고 임시저장한다. 개인저자는 최초 1회 정산정보 등록과 거래 승인을 마친다.
  6. 거래 승인 후 ‘판매신청’을 누른다. 검수·반려 수정 후 판매 승인을 받는다.
  7. 상품 페이지와 ISBN을 확인하고 1부를 주문해 실물을 검수한다. 이후 홍보와 월별 정산 관리를 시작한다.

완료 기준은 ‘신청 버튼을 눌렀다’가 아니라 상품 페이지에서 주문이 가능하고, ISBN 표시와 실물 품질을 확인했으며 정산내역을 조회할 수 있는 상태다.

‘퍼플’이라는 발행처로 출간합니다. 책의 고유번호 발급과 도서관 제출은 교보문고가 대행해요.

개인저자의 저작권·출판권·배타적 발행권한은 저자에게 있다는 것이 공식 안내다. 이전 출판계약이 있으면 해당 계약의 권리 범위를 먼저 확인한다. 다른 출판사 재출간이나 판매중지는 가능하나 기존 계약과 실제 신청 절차를 함께 확인한다. 출처 2

비용을 구분해서 예산 잡기

  • 서비스 기본 이용·주문분 제작·ISBN/납본 대행(개인저자): 공식 안내상 무료.
  • 저자가 직접 주문하는 확인용 책, 배송비: 주문 화면의 금액을 부담한다.
  • 교정·디자인 외주, 유료 폰트·이미지, 광고: 선택한 경우 별도 비용.
  • 공동대표·법인 전자계약에 필요한 유료 공동인증서: 보유 여부와 해당 계약의 요구 규격을 확인한 뒤 준비한다.

판매 경로는 인터넷·모바일 교보문고다. 오프라인 매장 진열 판매로 이해하지 않는다. 매장 직원에게 POD 주문을 문의하는 것은 가능하다. 전자책 출판은 별도 계약·경로이며 이 종이책 신청으로 함께 등록되지 않는다. 출처 2, 4

가입하고, 판매대금을 받을 정보를 등록하세요

구매할 때 쓰는 일반 회원 가입과 출판을 위한 파트너 가입은 별도입니다.

따라 하기

PC에서 파트너시스템 → 파트너 가입 → 개인저자를 선택하세요.

꼭 한 번 더

책 정보를 작성하고 임시저장한 뒤, 최초 1회 정산정보를 등록하고 거래 승인을 받으세요.

확인 포인트

완료 확인: 거래 승인이 끝나고, 저장한 책에 ‘판매신청’ 버튼이 보여요.

파트너시스템 열기 ↗
자세한 절차와 확인사항 보기＋

A. 성인 개인저자

  1. PC에서 파트너시스템 → 파트너 가입 → ‘개인저자’를 선택한다.
  2. 현재 가입 화면의 필수 정보, 연락받을 이메일·휴대전화 등을 입력하고 약관을 읽어 신청한다. 가입 완료 메시지와 안내 메일을 보관한다.
  3. 가입 승인을 기다린다. 상세 안내에는 2~3영업일, 최신 순서 요약에는 평균 1~2영업일로 적혀 있다. 일정에는 2~3영업일을 확보한다.
  4. 승인 후 로그인 → ‘바로출판POD관리’ → ‘POD등록’에서 상품 정보를 작성한다.
  5. STEP 1~5 작성 → ‘임시저장’ → 정산정보 등록 화면으로 이동한다. 최신 공식 요약은 이 순서로 최초 1회 정산정보를 받도록 안내한다.
  6. 본인 정산계좌와 요구 정보를 입력하고 개인 명의 통장 사본·신분증을 올린다. 공식 안내는 주민등록번호 뒷자리까지 보이는 신분증을 요구하므로, 현재 공식 등록 화면의 요구 범위·개인정보 안내를 확인해 그 화면에 제출한다. 문의 메일에 신분증을 임의 첨부하지 않는다.
  7. 거래 승인 결과를 확인한다. 공식 요약상 평균 1~2영업일이다. 승인 후 저장된 도서를 다시 열면 ‘판매신청’ 버튼이 표시된다.

완료 기준: 로그인 가능 + 정산정보 등록 완료 + 거래 승인 완료 + 해당 도서의 판매신청 버튼 표시. 일반 교보문고 구매회원 가입과 파트너·거래 승인은 별개로 확인한다. 출처 2

B. 출판사·사업자

  1. 사업자 형태에 맞게 개인사업자/법인사업자로 신청한다. 사업자·출판사 정보와 현재 화면에서 요구하는 증빙을 준비한다. 사업자등록증·출판사 신고 관련 증빙 등의 실제 제출 항목은 가입 화면·담당자 요청으로 확정한다.
  2. 예금주에 사업자명/대표자명이 함께 표시된 사업자 통장을 정산계좌로 준비한다.
  3. 1인 대표 개인사업자: 담당자의 가입 승인 후 등록한다.
  4. 공동대표 개인사업자·법인: 이메일로 전자계약을 받고 서명·계정 승인을 마친다. 공식 안내는 계약서 송부에 1주일 이상 걸릴 수 있다고 설명한다. 유료 공동인증서가 필요하므로 담당자 안내에 맞춰 준비한다.
  5. 제작 사양과 정가를 확정한 뒤 출판사가 직접 ISBN을 발급받고 판권·표지에 반영한다. 납본 역시 직접 진행한다. 기존 ISBN 도서는 재사용 가능 여부를 담당자에게 확인한다.

미성년자·대리신청: 성인 본인 신청 흐름을 그대로 적용하지 않는다. 공식 안내의 ‘미성년자 신청서류’에서 보호자 신분증과 우편 제출 서류를 확인하고 운영팀에 접수 방법을 확인한 뒤 진행한다. 출처 2

일반 워드의 ISO B5 크기를 이름만 보고 선택하지 않는다. 교보문고 도구에 표시된 실제 mm 수치를 쓴다. 초보자의 글 중심 책은 무선제본·흑백·A5(국판) 또는 신국판에서 검토를 시작하면 작업이 단순하다. 이는 작업 권장안이며 의무 사양은 아니다. 출처 3

선택 순서

  1. 공식 제작 가이드에서 무선/날개/양장을 고른다. A4는 무선만 가능하다. 정사각판·가로판은 날개를 선택할 수 없다. 선택 가능한 조합은 도구를 따른다.
  2. 판형 → 내지 인쇄 방식 → 용지 → 전체 PDF 페이지 수를 입력한다. 표지는 내지 흑백 여부와 관계없이 컬러다.
  3. 내지 용지를 선택한다. 현재 도구에는 백색모조 80·100·150g, 미색모조 80·100g, 이라이트 80g, 스노우 100g이 표시된다. 백색모조 150g은 현재 도구에서 컬러 전용이다.
  4. 책등 두께·표지 규격·내지 규격을 작업표에 기록한다. 양장이나 날개 표지는 무선 표지 계산식을 대입하지 않는다.
  5. 파트너시스템 → POD등록 STEP 1 하단 ‘더 많은 도움을 드릴께요’ → ‘가격책정 미리보기’에서 같은 사양으로 가격을 확인한다. 도구의 치수 계산과 실제 정가 계산은 구분한다.
  6. 목표 정가가 너무 높으면 판형·흑백·무선제본·페이지 수·용지를 조정해 재계산한다. 최종 등록 화면이 허용하는 가격으로 확정한다.

주의: 판매 승인 후 제작옵션(판형·용지·페이지 수 등)과 정가를 변경할 수 없다는 공식 안내가 있다. ‘일단 승인받고 나중에 바꾸자’는 방식으로 신청하지 않는다. 출처 2, 3, 4

책 안쪽 페이지를 PDF로 만드세요

‘내지’는 표지를 제외한 책의 안쪽 페이지를 뜻합니다. 원고만 쓰는 것에서 한 단계 더, 인쇄할 모양으로 편집하는 작업이에요.

쉽게 시작하기

공식 제작 도구에서 내지 템플릿을 받고, 그 문서에 원고를 옮겨 편집하세요.

꼭 확인하기

판권 페이지를 넣고, 한 페이지씩 PDF로 저장하세요. 첫 페이지는 책 오른쪽에서 시작해요.

확인 포인트

완료 확인: PDF를 다시 열었을 때 글자·그림·쪽번호가 정상이고, 파일 크기가 공식 규격과 같아요.

공식 제작 도구 열기 ↗
자세한 절차와 확인사항 보기＋

실제 작업 순서

  1. 공식 제작 도구에서 ‘내지 제작 가이드 선택’ → ‘내 사양으로 내지 템플릿 받기’를 이용한다. 선택 판형에 맞는 한글·워드 템플릿으로 원고를 옮긴다.
  2. 제목·본문·인용·표·그림·목차·쪽번호 스타일을 통일하고 교정한다. 표와 그림이 페이지 밖으로 나가지 않는지 확인한다. [작업 권장]
  3. 판권 페이지를 앞이나 뒤에 넣는다. 개인저자는 공식 판권 샘플에서 도서명·저자·발행일 등 저자가 수정할 부분만 바꾼다. 발행처 ‘퍼플’의 공식 정보는 최신 샘플을 따른다. 출판사는 자사 정보를 쓴다.
  4. 흑백으로 신청하면 PDF도 그레이스케일로 준비한다. 글꼴은 공식 안내에 따라 TTF를 사용하고 PDF에 포함되었는지 확인한다. 글꼴 오류가 있으면 공식 폰트 오류 안내를 따라 처리한다.
  5. PDF는 한 페이지씩 저장한다. 좌우 2쪽 모아찍기·소책자 인쇄 배치로 만들지 않는다. 첫 PDF 페이지는 실제 책의 오른쪽, 홀수는 오른쪽·짝수는 왼쪽이다. 목차 쪽번호와 PDF상의 물리적 페이지 번호는 구분한다.
  6. PDF를 다시 열어 페이지 크기, 총 페이지 수, 빈 페이지, 글자 깨짐, 표 잘림을 확인한다. 암호·편집 주석·템플릿 색상 안내선·교정 표시가 남지 않게 한다. [일부 작업 권장]

재단여분과 읽기 여백을 구분

  • 재단여분: 상하좌우 각각 3mm를 실제 책 크기 밖으로 더한다. 배경·사진이 끝까지 차는 페이지는 이 영역까지 채운다.
  • 예: 신국판 실제 152×225mm → 내지 PDF 158×231mm. A5(국판) 실제 148×210mm → 내지 PDF 154×216mm.
  • 읽기 여백: 글자가 제본에 묻히지 않게 안쪽을 넓힌다. 현재 제작 도구는 가운데 쪽 26mm, 바깥쪽·상하 20mm를 권장한다. 초보자는 템플릿 기본 여백을 그대로 사용한다.
  • 면지는 제작 시 제공되므로 면지용 페이지를 별도로 추가할 필요가 없다. 의도한 빈 페이지는 원고 구성에 맞게 넣고 전체 페이지 수에 포함한다. 출처 2, 3

페이지 수와 부분 컬러

공식 상세 안내의 원고 범위는 30~1,000p다. 제작 안정성과 납본을 위해 50p 이상을 권장한다. 50p 미만은 납본 제외 안내 및 STEP 5 요청사항 확인 문구가 있으므로 해당 규정을 확인한다. 30p 미만으로 임의 신청하지 않는다. 제본·용지별 실제 허용 범위도 등록 화면을 확인한다. 출처 2

부분 컬러는 최대 10p, 연속 페이지, PDF 기준 홀수 시작·짝수 종료 조건으로 안내된다. STEP 2에서 흑백 선택 → STEP 5 요청사항에 PDF 3~12페이지 부분 컬러 요청처럼 기록한다. 예상 정가가 올라갈 수 있으므로 최종가 반영을 확인한다. 출처 2

표지와 앞표지 이미지를 준비하세요

인쇄용 표지와 인터넷 서점에 보일 앞표지 이미지는 용도가 다릅니다.

간단한 방법

개인저자는 등록 화면에서 무료표지 디자인을 골라 제목과 이름을 입력할 수 있어요.

최종 페이지 수로 책등 두께를 계산하고, 공식 도구에서 맞춤 표지 PPT를 받아 작업하세요.

확인 포인트

완료 확인: 표지에 제목·저자·필요한 로고가 있고, 앞표지만 담은 JPG/PNG 이미지도 준비했어요.

공식 제작 도구 열기 ↗
자세한 절차와 확인사항 보기＋

가장 간단한 경로: 개인저자 무료표지

개인저자는 POD 등록 과정의 무료표지 기능에서 디자인을 선택하고 도서명·저자명을 입력할 수 있다. 공식 안내상 이 기능을 이용하면 별도 표지 PDF를 준비할 필요가 없다. 출판사·사업자는 직접 표지 파일을 제작한다. 무료표지 사용 전에도 내지 페이지 수와 책 사양을 먼저 확정한다. 출처 2

직접 디자인하는 경로

  1. 최종 페이지 수·용지를 공식 제작 도구에 입력한다. ‘표지 제작 가이드 선택’ → ‘내 사양으로 표지 PPT 만들기’를 이용한다.
  2. 무선 표지는 뒤표지+책등+앞표지가 이어진 한 장의 펼침면으로 만든다. 앞표지 한 면을 표지 전체 파일로 착각하지 않는다. 날개·양장은 해당 조합의 템플릿을 사용한다.
  3. 개인저자는 공식 퍼플 로고를 앞표지와 책등에 넣는다. 현재 도구는 책등 10mm 이하는 책등 로고 생략 가능하다고 안내한다. 출판사는 자사 로고를 쓴다.
  4. 뒤표지 오른쪽 아래 55×35mm 권장 확보 영역에는 글자·중요 이미지를 넣지 않는다. 현재 도구는 실제 바코드 스티커 45×25mm를 고려한 여유 영역으로 설명한다.
  5. 배경은 재단여분 끝까지 채우고 글자·로고·중요 이미지는 재단선 안쪽에 둔다. 템플릿의 빨간 테두리·작업 안내 문구는 삭제한다.
  6. 슬라이드 크기를 변경하지 않은 상태로 PDF 저장 → PDF 실제 크기와 책등 위치를 확인한다. 전체 내지 페이지 수가 바뀌면 표지를 다시 생성한다.

무선 표지의 단순 검산식은 가로=책 너비×2+책등+6mm, 세로=책 높이+6mm다. 예를 들어 국판 148×210mm, 책등 9.8mm라면 311.8×216mm다. 9.8mm는 특정 사양의 예시이므로 내 책에는 자동 계산값을 넣는다. 날개·양장에는 이 식을 사용하지 않는다. 출처 3

앞표지 이미지·미리보기

  • 썸네일은 앞표지만 JPG 또는 PNG로 별도 저장한다. 표지 전체 펼침면을 넣지 않는다.
  • 책소개·저자소개·목차를 텍스트로 별도 준비한다. 외주를 맡겨도 원본 PPT·내지 편집파일·최종 PDF를 함께 받는다. [작업 권장]
  • 미리보기 동의 시 자동 생성 기능을 이용할 수 있다. 공식 안내는 100p 이상: 앞표지+원고 1~18p, 100p 미만: 앞표지+전체 원고의 20% 미만이라고 설명한다. 제공 여부를 선택하고 공개될 앞부분을 검토한다.
  • 북카드·상세 이미지는 판매 승인 후 상품코드와 함께 운영팀에 반영 요청한다. 기본 파일 용량·이미지 픽셀 등의 제한은 업로드 화면의 현재 값을 따른다. 출처 2

자세한 절차와 확인사항 보기＋

개인저자

공식 기준은 등록 정가의 20%다. 누적 정산금 1만원 이상이면 익월 20일 자동 지급, 미달이면 이월된다. 최신 상세 이용안내와 개인정산 FAQ는 주말·공휴일이면 전 영업일 지급으로 설명한다. 일부 비교 FAQ에는 다음 영업일이라고 적혀 있으므로 실제 지급 일정은 정산 공지·장부로 확인한다. 출처 2, 4

개인 정산금은 공식 FAQ상 원천징수 후 등록 계좌로 지급하며 입금자명은 ‘교보전자책’이다. 이 가이드의 계산 예시는 세전이다. 실제 원천징수액·지급액은 정산 장부로 확인하고 세금 신고는 본인의 상황에 맞게 별도로 확인한다. 출처 4

예: 정가 20,000원×20%=1권당 4,000원. 2권 판매 시 8,000원으로 이월 대상, 누적 3권이면 12,000원으로 지급 기준을 넘는다. 취소·반품·정산 확정 내역에 따라 실제 지급 대상 수량은 달라질 수 있다.

매월 반복할 일

  1. 판매·취소·반품 수량과 정산 대상 기간을 조회한다.
  2. 파트너시스템 → 콘텐츠 정산 → 장부내역조회에서 지급 내역을 확인한다. 판매조회 메뉴는 현재 화면의 POD/정산 메뉴와 공식 ‘판매내역 조회방법’ 안내를 따른다.
  3. 개인은 누적액·이월액·원천징수·계좌 입금을 대조한다. 출판사는 계산서 승인 여부·마감일을 추가 확인한다.
  4. 정산 파일과 입금 증빙을 월별 보관한다. 장부상 지급 완료인데 입금이 없으면 예금주·계좌 상태를 확인하고 운영팀에 문의한다.
